# Hi, I'm Michał Cop

**Software architect and hands-on engineer working across AI, backend systems, and cloud infrastructure.**

I've been building software since 2018. Through **Better Nerf Technology**, I design and deliver AI-powered products, backend and full-stack applications, and cloud infrastructure—from architecture and implementation through deployment and operation.

## Flagship project

**[ParagraficAI](https://github.com/better-nerf-lex)** — my flagship project. The project was mostly build using AI toolkits and is AI backed lawyers management app with european law database integrations and document generator. I coworked with my lawyer friend on that one. Projest is unfinished, we gave up due to a lot of competition backed by multimillion companies emerged during time we developed it.

## What I build

- **AI systems:** agent orchestration, standalone agents, RAG pipelines, and AI-powered workflows.
- **Backend platforms:** APIs, microservices, asynchronous workers, payment integrations, and observable data flows.
- **Cloud infrastructure:** AWS and GCP/GKE environments, infrastructure as code, CI/CD, and deployment automation.

## Selected experience

- Independently designed the backend architecture for an AI product covering image analysis and user-behavior simulation. Implemented background workers and led interns during part of the engagement.
- Proposed the initial proof of concept for agent orchestration and standalone agents, then coordinated and collaborated on a migration to Amazon Bedrock AgentCore.
- Contributed to task-to-code architecture from the first design discussions and helped a task force deliver a Jira-to-Bitbucket automation MVP in 10 days, covering tickets, code, and deployments.
